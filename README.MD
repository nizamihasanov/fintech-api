# Secure FinTech API Lab

An intentionally vulnerable fintech-style API built with FastAPI for practicing application security testing and secure development workflows.

## Progress

| Phase | Description | Status |
|------|-------------|--------|
| 0 | Project setup + health endpoint | ✅ Complete |
| 1 | Core API + authentication | ⏳ Not started |
| 2 | Vulnerabilities introduced | ⏳ Not started |
| 3 | Exploitation walkthroughs | ⏳ Not started |
| 4 | Hardening + fixes | ⏳ Not started |

## Goals

- Simulate common web application vulnerabilities
- Practice vulnerability assessment and remediation
- Explore secure infrastructure using Docker and Nginx
- Document exploitation and hardening workflows

## Planned Vulnerabilities

- Broken authentication
- IDOR (Insecure Direct Object Reference)
- Weak input validation
- Missing rate limiting
- Insecure JWT handling

## Stack
- FastAPI
- SQLite
- Docker + Nginx
